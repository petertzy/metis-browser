# Contributing

Thanks for contributing to Metis Browser.

## Development

Requires Node.js 20 or later.

```sh
npm install
npm test
npm start
```

Please use English for source code, comments, documentation, commit messages, and user-facing interface strings.

## Pull requests

Keep changes small and focused. Include tests when changing URL validation or security-related behavior. Explain any new permissions, network behavior, or process privileges.

Do not disable Chromium sandboxing, context isolation, or web security to solve a compatibility problem.
